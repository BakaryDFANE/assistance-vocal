Recherche et voix gratuites pour BF

BF n'a besoin d'aucun serveur d'IA local. Les questions sont recherchees sur
Google, une reponse Wikipedia est lue a voix haute quand elle est disponible,
et les resultats Google sont ouverts dans le navigateur.

1. Installe les dependances:
   py -3.12 -m pip install -r requirements.txt

2. Verifie que le microphone et une voix francaise Windows sont disponibles.

3. Lance BF:
   py -3.12 assistant_bf.py

Exemples de commandes vocales:
   BF, quelle est la capitale de la France ?
   BF, cherche les horaires du train
   BF, ouvre Chrome
   BF, ouvre Spotify

Pour ouvrir une application, BF accepte les logiciels connus, les executables
accessibles dans le PATH et les raccourcis du menu Demarrer de Windows.
